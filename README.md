# NovaCart Shopify Theme v1.6.7

Modern, lightweight **Shopify Online Store 2.0** theme.  
Pure Liquid + Vanilla JS. Multi-currency, 5 color schemes, 4 languages (EN / AR / FR / ES).

---

## Quick start

1. In Shopify Admin go to **Online Store → Themes**
2. Click **Add theme → Upload zip file**
3. Upload: **`NovaCart_Shopify_Theme_Upload_v1.6.7.zip`**
4. Click **Customize**, configure, then **Publish**

## Main Customizer paths

- **Header group → Customize** — currency rates, logo, free shipping, marketing popup, product & collection features
- **Header group → Header** — color schemes, announcement bar, **Add Currency** blocks
- **Template** — homepage sections (Marquee, Categories, Promo, Featured collection, …)

---

## Features (summary)

- Online Store 2.0 sections & blocks
- Multi-currency display switcher (USD default)
- 5 color schemes + visitor switcher
- Languages: English, Arabic (RTL), French, Spanish
- Sidebar navigation
- Product: size chart, quick view, frequently bought together, shipping calculator
- Collection: filters, sort, grid/list, quick add
- Cart drawer + cart page
- Performance-minded (deferred JS, modular CSS)

---

## Important notes

- Currency switching is **display conversion** only. Checkout currency is controlled by Shopify Markets & Payments.
- Publish languages under **Settings → Languages** for the language switcher to list them.
- Replace demo content with your own products, logo, and collections before launch.
